# Snowdown — Roadmap & Milestones

## Milestone 0 — Design baseline
- source-of-truth docs exist;
- engine/backend decision made or consciously deferred;
- configurable gameplay values established;
- basic network architecture selected.

## Milestone 1 — Throw Lab
Single small test space, 1–2 players/bots if needed.
- first-person movement;
- pack snowball;
- charge/release projectile;
- projectile arc;
- head/body colliders;
- local hit feedback.

Success: throwing a moving target feels understandable and satisfying.

## Milestone 2 — Networked Core
- authoritative server;
- 4–8 players;
- replicated movement/projectiles;
- validated inventory;
- server hit registration/scoring;
- 5-minute round clock;
- scoreboard/results.

Success: repeated online matches are stable enough to playtest.

## Milestone 3 — Movement & Defense
- crouch tuning;
- slide;
- catch;
- improved hit reaction;
- near-miss audio;
- spawn safety.

Success: defense is skillful and readable rather than random.

## Milestone 4 — Alpine Village vertical slice
- coherent art pass;
- snow source distribution;
- rooftops/slopes/interiors;
- audio pass;
- final-ish FFA HUD;
- party/join flow prototype.

Success: external testers understand the product without explanation.

## Milestone 5 — Social/session foundation
- parties;
- join friend;
- private rooms;
- reconnect;
- post-match continuity;
- basic cosmetics/profiles.

## Milestone 6 — Content/balance
- additional maps;
- Team Snowfight;
- challenges/rewards;
- telemetry-driven balance;
- accessibility expansion.

## Explicitly later
Ranked, monetization, advanced snow deformation, large social lodge, many special snowballs, esports features, creator tools.

## Gate rule
Do not advance scope because a system is interesting. Advance only after the previous milestone answers its core risk with playtest evidence.
