# SNOWDOWN — CURATED VISUAL REFERENCE PACKAGE

Status: **LOCKED REFERENCE GUIDE / NOT A PRODUCTION-ASSET LICENSE**

Purpose: give Astra a small, intentional reference set instead of a random image pile.

## Governing rule

References communicate principles, not assets to copy. TAKE the listed material, lighting, scale, clothing, composition, or physical-behavior lesson. DO NOT copy distinctive authored composition, architecture, character identity, branding, logos, or proprietary game art.

Do not ship a reference image as a game texture or asset unless its exact license and intended use are separately verified.

## Licensing tiers

### Tier A — reusable production-source candidate
Poly Haven's official license states its assets are CC0. Individual selected assets can therefore be evaluated as actual texture/material source candidates.
Official license: https://polyhaven.com/license

### Tier B — photography/reference candidate
Unsplash's standard license permits broad free commercial and non-commercial use subject to its restrictions. Snowdown should still use these photographs primarily as visual references rather than baking photography into the authored world.
Official license: https://unsplash.com/license

### Tier C — file-by-file verification
Wikimedia Commons licenses vary per file. Verify the exact file description page, attribution, and share-alike requirements before reuse.
Reuse guide: https://commons.wikimedia.org/wiki/Commons:Reusing_content_outside_Wikimedia/licenses/en
