# Snowdown — Visual & Feel Direction

## Tone
Playful, energetic, welcoming, expressive, wintry and slightly exaggerated. Cozy between matches; chaotic but readable during matches.

## Visual language
Prefer:
- snow splat;
- puff;
- tumble/stumble;
- scarf flutter;
- hat spin;
- whoosh;
- crunch;
- plop/thump;
- strong readable silhouettes;
- visible projectile arcs and misses.

Avoid military or lethal visual language. Avoid gore, death framing, weapon/bullet vocabulary, or effects that make the game read like a reskinned firearm shooter.

## Readability priorities
1. Player silhouette and facing direction.
2. Incoming snowball visibility.
3. Throw charge/readiness.
4. Head/body hit feedback distinction.
5. Snow sources and interactable surfaces.
6. Cover/routes/spawn readability.
7. Score and round-state clarity.

## Reference workflow
The `references/` folder is intentionally reserved for user-approved visual targets. When references exist, compare implementation screenshots against them and report the largest discrepancies in silhouette, palette, composition, lighting, readability and emotional tone.

Do not invent a permanent art style from generic defaults when the user has not yet provided or approved references.
